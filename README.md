# finance_cli

个人记账工具（基于 Python + Streamlit + SQLite）。

**主要功能**
- 添加账目：金额、收支类型（收入/支出）、支付方式（支付宝/微信）、分类、日期、备注
- 支持的分类：餐饮、美食、交通、购物、娱乐、王者荣耀、电话费、水电费、居住、家居用品、奶茶饮料、投资理财、好评返现收入、医药、人情世故、教育培训、父母家庭开支、AI支出、其他（列表与图表均带图标）
- 分类可细分：餐饮（早餐 / 午餐 / 晚餐 / 买菜 / 酸奶）、美食（零食 / 詹记 / 蛋糕/糕点）、购物（化妆品），展示为「小类~大类」形式（如"早餐~餐饮"），统计归属大类汇总；旧数据（如原"零食"记录）启动时自动归入对应大类
- 首页 KPI 卡片：本月收入 / 支出 / 结余 / 笔数（较上月变化）以及今日支出总额与笔数（较昨日变化）
- 列表与筛选：默认显示当日支出账目，支持上一日/下一日按钮翻页浏览每日数据（翻页时左侧添加表单的日期同步联动），可按日期、年份、月份、分类、收支类型、支付方式过滤，支持分页与每页条数设置
- 编辑与删除：单击列表任意一行，可弹窗编辑整条账目或确认后删除
- 统计视图：月度收支趋势、分类金额排行、收支类型与支付方式环形图及统计表（占比进度条）
- 导出 Excel：生成包含账单明细、分类统计、类型统计、支付方式统计、月度汇总与统计图的工作簿
- 快速导出：当前筛选结果可一键导出 CSV

**快速开始**
1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 在项目目录运行应用：

```bash
streamlit run app.py
```

3. 在浏览器打开 http://localhost:8501 并使用页面表单添加、筛选或导出账单。

**项目结构**
- app.py：Streamlit 页面与交互逻辑
- db.py：SQLite 初始化、模式（schema）检查与 CRUD 接口
- models.py：收支类型、支付方式与分类常量列表
- services.py：数据格式化与表格/统计准备函数
- exporter.py：导出 Excel（含图表）实现
- finance.db：本地 SQLite 数据库（运行时生成）
- .streamlit/：Streamlit 配置（部署时使用）

**数据库与向后兼容性**
- 程序启动时会自动创建数据库，并在需要时通过 ALTER TABLE 为旧数据库添加 `transaction_type` 与 `payment_method` 字段以保持向后兼容。

**导出说明**
- 导出文件包含以下工作表：`账单明细`、`分类统计`、`类型统计`、`支付方式统计`、`月度汇总`、`统计图`。
- 各统计表带表头样式、数字格式与合计行；图表以图片形式嵌入 Excel 文件。

**测试**
- 项目内含单元测试与 AppTest 冒烟测试（位于 `tests/`），可运行：

```bash
python -m unittest discover -v
```

**部署**
- 宝塔面板部署（推荐，图形化界面、最省心）：按 [DEPLOY_BAOTA.md](DEPLOY_BAOTA.md) 分步操作，约 30 分钟完成
- 纯命令行部署：按 [DEPLOY_SERVER.md](DEPLOY_SERVER.md)（systemd 方式）
- Streamlit Community Cloud（免费，但 SQLite 数据不持久）：按 `STREAMLIT_DEPLOY.md` 中的步骤部署
- 应用内置访问密码门：本地未配置密码时免密使用；在 `.streamlit/secrets.toml` 设置 `APP_PASSWORD`（或环境变量）后，访问需输入密码（公网部署建议开启）
